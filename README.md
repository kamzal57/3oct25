# Notes App - Multifunctional Note-taking Application

A native desktop note-taking application built with Vite, ReactJS, and Tauri (Rust).

## Features

- Create, edit, and delete notes
- Rich text editing capabilities
- Local storage persistence
- Modern, responsive UI
- Native desktop performance

## Prerequisites

Before running this application, ensure you have:

- Node.js (v20 or higher)
- Rust and Cargo
- System dependencies for Tauri (see [Tauri Prerequisites](https://tauri.app/start/prerequisites/))

## Installation

```bash
npm install
```

## Development

Run the application in development mode:

```bash
npm run tauri dev
```

## Build

Build the application for production:

```bash
npm run tauri build
```

## Technologies

- **Vite** - Fast build tool and development server
- **React** - UI library for building the interface
- **Tauri** - Framework for building native desktop apps with Rust
- **Rust** - Backend runtime for native performance
